How to create or restore a backup
  • Manual backup: Double-click D:\PrintingERP\backup_now.bat on the ERP server computer.
  • Restore: Double-click D:\PrintingERP\restore_erp.bat (interactive, requires confirmation).
  • Automatic (morning): Runs on server startup after a configurable delay. One backup per day max.
  • Backups are stored locally on this server — never exposed over the LAN or to employees via Django URLs.
